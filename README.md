# MGT 408 · HW5 — Campus Customs multi-agent operations

Everything is in [`hw5/`](hw5/). Start with [`hw5/README.md`](hw5/README.md) for setup and run steps (MCP server, FastAPI backend, React board, and resetting the database).

- Agents: PydanticAI (`gpt-6-luna` via Portkey), Boss + Inventory + Accounting + Facilities + Customer Service
- Tools: the campus-customs MCP server over `hw5/data/campus_customs_new.db`
- Deliverables: `hw5/output/`

Bring your own `PORTKEY_API_KEY` in `hw5/.env` (copy `hw5/.env.example`). No real keys are in this repo.
